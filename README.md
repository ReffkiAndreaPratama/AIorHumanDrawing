## ⚠️ Disclaimer

This system produces **statistical estimates** based on visual patterns learned from training data.
It is **not a forensic tool** and cannot definitively confirm whether an image is human-made or AI-generated.
Results may be less reliable for:

- Heavily compressed or screenshot-captured images
- AI drawings that have been manually edited or post-processed
- Styles not well-represented in the training data

## 🧠 How It Works

```
Upload Image
     │
     ▼
Preprocessing (resize 256×256, grayscale)
     │
     ▼
Feature Extraction
  ├─ GLCM (contrast, energy, homogeneity, correlation, ASM)
  ├─ Edge (density, gradient statistics, Laplacian variance)
  ├─ FFT (low/high frequency energy ratio)
  ├─ Statistical (pixel entropy, local variance)
  ├─ Color (HSV histogram statistics)
  └─ Noise (Gaussian residual estimation)
     │
     ▼
Soft-Voting Ensemble
  ├─ SVM (RBF kernel)
  └─ Random Forest (300 trees)
     │
     ▼
Prediction + Confidence Score
```

## 🚀 Getting Started

### 1. Clone & set up Python environment

```bash
git clone https://github.com/yourusername/ai-human-drawing-detector.git
cd ai-human-drawing-detector

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Prepare dataset

Place your images into the correct folders:

```
dataset/train/human/    ← human drawings / sketches
dataset/train/ai/       ← AI-generated drawings
dataset/validation/human/
dataset/validation/ai/
dataset/test/human/
dataset/test/ai/
```

**Suggested dataset sources:**

| Source | Content |
|---|---|
| [DiffusionDB](https://huggingface.co/datasets/poloclub/diffusiondb) | AI-generated images |
| [QuickDraw Dataset](https://quickdraw.withgoogle.com/data) | Human sketches |
| [Sketchy Database](http://sketchy.eye.gatech.edu/) | Human sketches |
| Custom scans | Your own hand-drawn sketches |

### 3. Train the model

```bash
python src/train.py
```

Output: `model/drawing_detector.joblib`

### 4. Evaluate on test set

```bash
python src/evaluate.py
```

Outputs: accuracy, classification report, `model/confusion_matrix.png`, `model/roc_curve.png`

### 5. Run a single prediction (CLI)

```bash
python src/predict.py path/to/image.png
```

### 6. Start the API

```bash
uvicorn api.main:app --reload --port 8000
```

API docs available at: http://localhost:8000/docs

### 7. Start the frontend

```bash
cd frontend
cp .env.example .env       # configure API URL if needed
npm install
npm run dev
```

Open: http://localhost:5173

## 🔬 Extending the Project

### Option A — Add XGBoost

In `src/train.py`, replace or extend the `VotingClassifier`:

```python
from xgboost import XGBClassifier
xgb = XGBClassifier(n_estimators=300, learning_rate=0.05, use_label_encoder=False)
```

### Option B — CNN / Transfer Learning (Level 2)

For larger datasets, replace the feature extraction stage with a pretrained backbone:

```python
# PyTorch + torchvision
from torchvision.models import efficientnet_b0
model = efficientnet_b0(pretrained=True)
# Fine-tune the classifier head for 2 classes
```

### Option C — 3-class problem

Extend the dataset and label map to include:

```
human/    ← pencil, pen, scanned drawings
ai/       ← AI-generated artwork
digital/  ← digital art (Procreate, Illustrator, etc.)
```
